# Event Lab

Event Lab is a social development events platform for creating and joining community activities such as cleanups, plantation drives, donation campaigns, workshops, and conferences.

**Live Site:** Add the deployed Vercel or Render URL here after deployment.

## Features

- Discover upcoming community events in a responsive grid.
- Create future-dated events with complete event details.
- View event details and join events after authentication.
- Track joined events sorted by event date.
- Manage, update, and delete events created by the logged-in user.
- Switch between polished light and dark themes.
- Access protected event creation and management pages securely.
- Use responsive navigation, profile controls, authentication pages, and an eye-catching footer.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the application.
